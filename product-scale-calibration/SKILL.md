# Product Scale Calibration

## 目标

在生成或合成生活场景前，建立商品与环境之间的尺度关系。校准必须有尺寸证据、场景几何或明确假设；“看起来差不多”不能作为比例准确的依据。

本 Skill 区分三种结果：
- METRICALLY_GROUNDED：尺寸和场景参照有可信物理依据。
- VISUALLY_APPROXIMATED：只能做视觉近似，明确记录估算和限制。
- SCALE_UNVERIFIED：缺少足够信息，不能宣称比例准确。

## 前置输入

- product-identity.json：确认当前 SKU、几何和权威参考视角。
- product-dimensions.json：产品尺寸、轴定义、测量状态、来源和公差。
- 场景草图/背景/3D 场景：相机视角、地面/桌面/墙面、消失点和接触面。
- 参照物资料：只有尺寸已知、位置/平面明确的物体才可用于尺度校准。
- 人物资料：若需要人物比例，记录人物身高来源；未知身高不得当作精确标尺。

## 核心限制

1. 单张无标尺照片通常不能恢复完整三维尺寸。
2. 仅有一个已知长度，只能约束与该长度同一测量方向/平面上的尺度；不能自动推出其他轴。
3. 2D 像素比例只在同一平面、相近深度且透视处理合理时才可直接比较。
4. 地面平面的单应性/透视变换不能用来任意变形直立产品。
5. 不知道镜头、相机姿态或场景几何时，不得声称完成精确相机标定。
6. 不得把 AI 生成的家具、门框、人物或道具当作已知尺寸参照，除非其尺寸明确设定并由可控 3D/合成流程保证。
7. 不允许通过非等比拉伸、液化或局部生成式重绘来“修正”产品比例。

## 校准流程

### 1. 锁定产品尺寸与方向
- 读取已验证长宽高、轴定义、测量状态和公差。
- 将产品主视图、实际拍摄角度和可见尺寸轴对应起来。
- 缺少关键轴或尺寸来源冲突时，降低校准状态或暂停。

### 2. 建立场景坐标
- 定义世界坐标：地面/桌面/墙面、原点、水平轴、深度轴和竖直轴。
- 明确产品接触点、支撑面、悬挂点或安装位置。
- 记录参照物尺寸、来源、所在平面、距离/深度和可见边界。
- 若场景由 3D/CAD 构建，优先在真实单位（mm/cm/m）中布置产品和道具。

### 3. 建立相机/投影关系
- 记录相机位置、高度、俯仰、方位、焦距/视角、传感器/画幅信息（可得时）。
- 记录地平线、消失点和接触平面。
- 说明使用的投影方法：正交、透视相机、已知平面单应性、人工 2D 近似或未知。
- 不具备完整相机参数时，明确哪些尺度关系仅为视觉近似。

### 4. 计算与验证
- 对同平面且透视可忽略的对象，可使用有依据的像素/物理尺寸比。
- 透视场景中，尺度随深度变化；必须使用相机/3D 几何或同深度参照，不可套用单一全局缩放因子。
- 2D 合成优先保持产品原图几何，只调整整体等比尺寸、位置和接触阴影。
- 如需明显改变相机视角或产品可见侧面，改用对应实拍或可信 CAD/3D 渲染，不从单张照片臆造。
- 记录校准残差、容差或无法量化的原因；没有测量依据时不编造误差百分比。

### 5. 人物比例
- 有用户确认身高/尺寸时可作为尺度参考，并记录来源。
- 没有身高资料时，人物只能作为视觉人物，身材比例标为估算，不作为精确测量基准。
- 人物与商品必须处于合理的空间位置；同一地面平面、接触面和相机透视应一致。
- 人物姿态不能暗示商品具有未经证实的承重、人体工学或安全性能。

## 输出

生成 scale-calibration.json，至少包含：
- sku、status、unit、product_dimension_source。
- scene_reference、scene_coordinate_system、contact_planes。
- reference_objects：尺寸、证据、所在平面和可见边界。
- camera：已知参数、未知参数、视角和投影方法。
- placement：产品锚点、落点、旋转、等比缩放和遮挡关系。
- person_scale：人物尺寸来源或估算状态（如适用）。
- method、assumptions、uncertainties、validation、limitations。
- approval_required 和下一步补充资料。

同时输出一张尺度规划草图/标注图，显示产品占位、接触点、参照物、相机方向和关键尺寸。

## 下游验收

- 场景合成前，lifestyle-scene-composite 必须读取本文件。
- 人物场景由 product-human-scene-integration 读取同一尺度方案。
- 规格图必须读取 product-dimensions.json，而不是从场景图反推尺寸。
- QA 分开记录“视觉上协调”和“物理尺度有依据”，不得混为一个 PASS。

若状态为 SCALE_UNVERIFIED，只允许制作明确标注的氛围概念图；不得宣称尺寸准确，不得使用强烈尺度暗示道具，并应请求补充实测尺寸、参照物或 CAD/3D。

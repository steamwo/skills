# Product Reference Audit

## 目标

在开始设计或生成图片前，盘点用户提供的商品照片和资料，确定每个素材实际能证明什么。禁止用推断填补未拍摄的结构。

## 执行步骤

1. 查找当前项目中用户提供的照片、视频帧、尺寸图、CAD、包装图和 SKU 文档。
2. 为每个文件记录路径、文件类型、像素尺寸、方向、清晰度、曝光、反光、遮挡和背景复杂度。
3. 识别视角：正面、背面、左/右侧、俯视、仰视、底面、局部细节、尺寸示意或场景照。无法判断时标为 unknown。
4. 列出照片中直接可见的产品特征：轮廓、部件数量、孔位、接缝、纹理、颜色、五金和边缘。
5. 对每个计划使用的卖点/参数，标明证据来源与可信状态。
6. 生成缺失素材清单，并按对主图、细节图、规格图和详情页的影响排序。

## 证据状态

- visible：照片直接可见。
- user_confirmed：用户明确确认。
- document_verified：由用户提供的规格/工程文档支持。
- estimated：只能估算，不可作为规格承诺。
- unknown：没有足够证据。
- conflicting：不同来源相互矛盾。

## 强制限制

- 一张三分之四视角图不能证明背面、底面或隐藏结构。
- 照片中出现的物件数量不能证明售卖数量或包装清单。
- 不根据外观猜木种、材质等级、承重、食品接触等级、环保认证或尺寸。
- 网络竞品图只能做风格参考，不能作为当前 SKU 的结构或材质证据。
- 不因图片不完整而擅自“补全”产品视角。

## 输出

在项目 QA/plan 目录生成：

- asset-audit.md：逐文件素材清单。
- evidence-matrix.csv 或 JSON：商品特征、证据来源、状态。
- missing-assets.md：需要补拍或补充的资料。
- usage-map.md：每张源图适合用于哪些输出，以及不可支持哪些内容。

审查完成后将结果交给 product-identity-lock 和 ecommerce-gallery-planner。

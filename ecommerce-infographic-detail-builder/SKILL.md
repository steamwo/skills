# Ecommerce Infographic & Detail Builder

## 目标

将已核实的商品信息组织成清晰易读的电商图文。图像模型负责背景/氛围，不负责生成最终中文文案、数字或技术参数。

## 输入

- 已通过身份锁定的商品图片。
- 用户确认的商品名称、卖点、尺寸、材质、数量、包装和使用说明。
- 品牌字体、颜色、Logo 和视觉规范。
- 图片计划及目标平台规则。

## 内容设计

- 主标题：一句话表达当前模块的主题。
- 副标题：补充一项已证实的信息。
- 卖点模块：每条卖点对应一个证据来源。
- 细节标注：引线、编号或局部放大框必须指向真实细节。
- 尺寸图：标注测量方向、数值、单位和测量口径。
- 包装图：区分商品本体、配件、赠品和包装材料。
- 详情页：商品整体 → 价值点 → 场景 → 材质/结构 → 尺寸 → 包装/注意事项。

## 制作规范

1. 先锁定文案原文，建立 copy-deck。
2. 使用程序或设计工具排版文字、数字、图标和尺寸线。
3. 中文字体必须可用且有适当授权；检查字重、标点和移动端可读性。
4. 不让图像模型写中文字、数字或 Logo。
5. 文字与商品图层分开，方便编辑。
6. 每个详情页分屏独立保存，最后再拼接成长图。
7. 尺寸线和箭头不可遮挡商品关键结构。
8. 未提供尺寸时不生成比例尺或看似精确的尺寸标注。

## 输出

- copy-deck.md：逐条文案与证据。
- 每个独立分屏 PNG/源文件。
- detail-long.png：拼接长图。
- QA 报告：错字、数值、遮挡、层级、可读性和证据核验。

如果任何卖点缺乏证据，删去该卖点或标记待确认，不得用营销语言补齐事实。

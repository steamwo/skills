# Ecommerce Visual QA

## 目标

逐张检查产品图，并检查整套图片的一致性。不得把自动检测结果包装成真实性认证。

## 检查阶段

### A. 商品身份
- 轮廓、比例、部件数量、连接关系与参考图一致。
- 孔位、接缝、五金、Logo、倒角和边缘无变化。
- 没有生成不存在的背面、底面或内部结构。

### B. 材质与颜色
- 纹理方向、木节、天然色差和表面处理可信。
- 没有磨平、重绘、补造或复制纹理。
- 商品颜色没有被品牌调色或场景色污染。
- 不把无漆等同于零处理、无甲醛或食品级。

### C. 抠图与合成
- Mask 未吞掉孔洞、细杆、透明件或边缘。
- 无明显白边、黑边、锯齿和背景残留。
- 商品视角、尺度、透视、接触面和阴影协调。
- 背景没有出现误导性同款商品或虚构配件。

### D. 文案与参数
- 中文错字、数字、单位、标点和字体渲染正确。
- 每条卖点均有证据。
- 尺寸、数量、重量、包装和兼容性准确。
- 无未经证实的认证、性能或安全承诺。

### E. 品牌与整套一致性
- 字体、色彩、留白、图标和版式统一。
- 不同图片中的商品颜色、结构、件数和文案一致。
- 图片顺序符合购买决策路径，信息不重复或矛盾。

### F. 平台导出
- 平台、类目、槽位、规则来源与核验日期明确。
- 文件尺寸、比例、格式、大小和命名符合已核验规则。

## 报告格式

每张图输出：
- asset、sku、reference_images、checks。
- status：PASS / REVIEW / FAIL / NOT_CHECKED。
- evidence：具体对照图、字段或像素检查。
- issues：问题位置、严重度、修正建议。
- reviewer：人工审核状态。

整套图额外检查跨图一致性。身份或事实问题为 FAIL；缺少证据为 REVIEW 或 NOT_CHECKED，不能默认通过。

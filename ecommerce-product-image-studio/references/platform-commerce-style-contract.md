# Platform Commerce Style Contract

## Purpose

Marketplace style is not just aspect ratio.

Separate two layers:

1. **Compliance profile** — official/current platform requirements.
2. **Commerce style profile** — a heuristic creative strategy for how the platform tends to convert.

Commerce style profiles are **not official rules** and MUST NOT be described as such.

## Platform style dimensions

A profile SHOULD define:
- \`traffic_context\`
- \`decision_mode\`
- \`information_density\`
- \`scene_priority\`
- \`person_priority\`
- \`spec_priority\`
- \`value_emphasis\`
- \`trust_emphasis\`
- \`emotional_hook\`
- \`copy_density\`
- \`thumbnail_readability\`
- \`recommended_asset_mix\`
- \`avoid\`

## Taobao / Tmall / 1688 heuristic

Primary logic:
- shelf / search / comparison commerce;
- longer evaluation chain;
- strong detail-page role;
- buyers often need product, structure, material, dimensions, usage, variant, package and trust information.

Creative tendencies:
- hero can be clean and premium;
- detail modules may carry denser information than social-commerce assets;
- scenes support desire, but factual detail modules complete the purchase decision;
- visual system should stay consistent across a long page;
- modular detail screens are preferred masters; long image is a derivative.

Avoid:
- eight near-identical mood shots;
- excessive empty editorial space with little buying information;
- burying specs / variants behind atmosphere.

## Pinduoduo heuristic

Primary logic:
- fast value judgement;
- high need for instant clarity;
- thumbnail / small-card readability matters;
- specification, quantity, bundle and value information should be quickly understandable.

Creative tendencies:
- direct hierarchy;
- larger, shorter copy when copy is used;
- high product salience;
- obvious variant / bundle choices;
- fewer decorative elements;
- benefits and concrete value should be immediately legible.

Avoid:
- luxury-editorial layouts that hide the product;
- tiny copy;
- excessive visual storytelling before the offer / product is understood;
- fake discounts or unsupported value claims.

## Douyin commerce heuristic

Primary logic:
- content + shelf commerce;
- attention → interest → trust → purchase;
- mobile-first;
- scenes, people, usage moments and content-native framing have high value.

Creative tendencies:
- strong first-screen product recognition;
- believable in-use scene;
- natural people / hands / movement when useful;
- image should feel like a high-quality content frame, not a sterile catalog board;
- scene must remain relevant and clean;
- product and cover/content relevance must be obvious.

For Douyin product cards, current official guidance should be checked separately. Current platform materials emphasize clean composition, clear product subject, multiple useful views/details, and high-quality product information.

Avoid:
- clutter / unrelated props;
- low-quality cutout look;
- overlaid “sticker wall” aesthetics;
- pure text cards;
- content that looks disconnected from the product;
- distorted people or exaggerated low-quality beauty effects.

## Generic conversion rule

For every platform:
- product recognition happens first;
- one asset should have one dominant job;
- scenes need a believable story;
- detail images need a proof target;
- information graphics need exact copy and mobile readability;
- platform style never authorizes unsupported product claims.

# Claude Code project instructions

Read `.agents/skills/wood-product-fidelity/SKILL.md` and `AGENTS.md`.

User task: high-fidelity images for unpainted solid-wood home products.

Quick start: `python generate.py --input input/product.jpg --output output` after installing `requirements.txt`. Do not modify wood grain or product structure; never treat a new AI-generated viewing angle as real photography. The first edition uses background removal and programmatic composition, not an automatic text-to-image API.
